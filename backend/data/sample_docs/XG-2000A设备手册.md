# XG-2000A 设备手册

## 1. 技术参数

### 1.1 电气参数

| 参数 | 数值 |
|------|------|
| 额定电流 | 10A |
| 额定电压 | 220V |
| 额定功率 | 2.2kW |
| 工作频率 | 50Hz |

### 1.2 物理参数

| 参数 | 数值 |
|------|------|
| 外形尺寸 | 420×260×180mm |
| 重量 | 12.5kg |
| 防护等级 | IP54 |

## 2. 安装要求

2.1 设备应安装在干燥通风处，环境温度 -10℃ ~ 40℃。
2.2 安装面需能承受设备重量 3 倍以上的负载。
2.3 电源线截面积不得小于 2.5mm²。

## 3. 维护保养

3.1 每月检查一次接线端子是否松动。
3.2 每半年更换一次空气滤芯。
3.3 出现异响应立即停机检修。

## 4. 常见故障

4.1 无法启动：检查电源是否接通、保险丝是否熔断。
4.2 运行异响：可能为轴承磨损，需更换轴承。
4.3 过热保护：检查散热风扇是否正常运转。
