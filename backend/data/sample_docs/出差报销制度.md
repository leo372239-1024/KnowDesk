# 出差报销制度

## 1. 住宿标准

1.1 一线城市（北京、上海、广州、深圳）住宿标准为 500 元/晚。
1.2 其他城市住宿标准为 300 元/晚。
1.3 住宿超标部分由个人承担。

## 2. 交通标准

2.1 高铁二等座、飞机经济舱实报实销。
2.2 市内交通每日限额 100 元。

## 3. 例外情况

3.1 参加会议且会议指定酒店的，可据实报销，不受住宿标准限制。
3.2 因工作紧急需乘坐商务座的，需提前经部门负责人审批。

## 4. 报销流程

4.1 出差结束后 7 个工作日内提交报销单。
4.2 报销单需附发票、行程单。
4.3 审批路径：部门负责人 → 财务审核 → 出纳打款。
